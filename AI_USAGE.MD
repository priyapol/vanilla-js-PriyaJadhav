## Scope of Assistance

ChatGPT was used as a supporting tool during development to help understand concepts, troubleshoot issues, review code, and get guidance on testing. I reviewed the suggestions, made the changes I considered useful, and tested the results to ensure they worked as expected.


## Planning and Explanations

- Discussed the website structure and shopping flow to understand how users navigate from browsing products to completing  checkout.
- Used ChatGPT to understand JavaScript modules, API requests, browser local storage, and error handling.
- Explored how product information from the Noroff API could be used to implement features such as product search, filtering, product details, and shopping cart functionality.

## Debugging and Code Improvements

- Used ChatGPT to identify spelling mistakes, incorrect CSS selectors, and mismatched HTML IDs.
- Received explanations and suggestions for fixing missing brackets and incorrect HTML nesting.
- Investigated errors related to unavailable DOM elements and JavaScript variable scope.
- Received suggestions for improving network error handling when API requests fail.
- Reviewed the suggested corrections and tested the relevant functionality after making changes.
